🎯 ARCHITECTURE

  State Flow:
    User clicks button
        ↓
    heroController detects click
        ↓
    quantStateManager.toggle() called
        ↓
    State updated in memory
        ↓
    Custom DOM event dispatched
        ↓
    heroController listens to event
        ↓
    DOM updated (colors, text, indicators)

  No two-way binding, no circular updates, clean separation of concerns.

  Event System:
    • 'trading-real-toggled' → When trading mode changes
    • 'training-toggled' → When training mode changes
    • 'kill-switch-activated' → When emergency stop pressed

  Multiple components can listen. Decoupled architecture.
