🔄 DATA FLOW

  User clicks button
       ↓
  heroController detects click
       ↓
  quantStateManager.toggleTradingReal(true) called
       ↓
  [Our override intercepts]
       ↓
  setTradingRealBackend(true) calls POST /api/bot/trading-real/on
       ↓
  Backend responds: {ok: true} or {ok: false}
       ↓
  If OK:
    • Update local state
    • Emit event
    • Update DOM (green pulsing)
    • Log event to system

  If Error:
    • Log error to system
    • Don't change state
    • DOM stays unchanged
